# AI-Powered Lost and Found Matcher

An AI-based Lost and Found web application designed to make it easier to report and manage lost and found items.

Users can report a lost item or a found item by providing details such as the item name, category, description, color, brand, location, date, and an image.

The project will later use AI-based techniques to identify possible matches between lost and found items.

---

## Problem Statement

Traditional lost and found systems often depend on manual searching and text-based descriptions. It can be difficult and time-consuming to find a matching item when many lost and found reports exist.

This project aims to develop an AI-powered system that can help identify possible matches between lost and found items using item information and images.

## Current Pages

### Home Page

The home page introduces the project and provides two main options:

- Report Lost Item
- Report Found Item

### Report Lost Item

Users can enter information about a lost item.

Fields include:

- Item Name
- Category
- Description
- Color
- Brand
- Lost Location
- Date Lost
- Item Image

### Report Found Item

Users can enter information about a found item.

Fields include:

- Item Name
- Category
- Description
- Color
- Brand
- Found Location
- Date Found
- Item Image
